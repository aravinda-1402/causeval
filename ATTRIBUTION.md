## Research citation

Please cite the software when it supports a paper, benchmark, or research
artifact. GitHub's **Cite this repository** feature uses [CITATION.cff](CITATION.cff).
For the current software version, you can also use:

```bibtex
@misc{jatavallabha2026causeval,
  author = {Jatavallabha, Aravinda Raman},
  title = {CausEval: Causal Rule Coverage for AI Behavioral Contracts},
  year = {2026},
  howpublished = {\url{https://github.com/aravinda-1402/causeval}},
  note = {Software, version 0.1.0}
}
```

Record the version or commit you actually used alongside your results so the
work can be reproduced. This is a software citation; there is no associated
paper or DOI.
