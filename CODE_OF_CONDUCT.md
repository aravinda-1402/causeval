# Code of conduct

Be respectful, constructive, and inclusive. Discuss evidence and ideas rather than attacking people. Harassment, discrimination, threats, doxxing, and sharing private information without permission are not acceptable.

Maintainers may edit or remove harmful content, warn participants, or restrict participation for violations. Enforcement should be proportionate and applied consistently. Report concerns privately through the repository owner's contact details or GitHub private reporting once the repository is published. Do not post private incident details in public issues.
